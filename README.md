# Internal Mobility Analysis

Analysis of internal employee mobility patterns, transfers, promotions, and career progression.

## Project Structure

```
internal-mobility-analysis/
├── data/
│   ├── raw/          # Raw source data (not committed)
│   └── processed/    # Cleaned and transformed data
├── notebooks/        # Exploratory and reporting notebooks
├── src/              # Reusable analysis modules
├── reports/          # Output reports and visualizations
└── tests/            # Unit tests for src modules
```

## Setup

```bash
pip install -r requirements.txt
```
